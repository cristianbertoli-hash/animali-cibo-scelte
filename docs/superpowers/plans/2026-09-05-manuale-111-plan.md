# Manuale 111 pagine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produrre la versione italiana 2026.1 del manuale “Animali, cibo e scelte” in 111 pagine A5, con testo ampliato, infografiche mature, sezione mense fotocopiabile, PDF pubblico protetto e master stampa.

**Architecture:** Riutilizzare il generatore HTML/CSS del manuale da 72 pagine come base, separando contenuto editoriale, rendering grafico e protezione PDF. Estendere il modello pagina con tipi specifici (testo, infografica, ricetta, fac-simile, riferimenti) e mantenere una singola identità visiva. Il PDF viene generato da HTML con Chromium, renderizzato in PNG per QA e poi protetto con AES-128 compatibile con Anteprima macOS Big Sur.

**Tech Stack:** Python 3, HTML/CSS, SVG inline, Chromium/Playwright tramite `html_to_pdf.py`, pypdf, pytest, script PDF skill per render/preflight/compare.

**Spec:** `docs/superpowers/specs/2026-09-05-manuale-111-design.md`

## Global Constraints
- 111 pagine digitali A5 verticali.
- Target 10+ fino all'adulto; tono divulgativo + narrativo + pratico.
- Nessuna grafica infantile.
- PDF pubblico: apertura libera, stampa libera, accessibilità consentita, modifica/assemblaggio limitati.
- PDF stampa: non protetto e mantenuto privato.
- Materiali caricati usati come base editoriale, ma dati scientifici/normativi aggiornati e verificati.
- Max 4 siti finali di riferimento: WHO, EFSA, FAO, SSNV.
- Nessuna owner password nel repository pubblico.
