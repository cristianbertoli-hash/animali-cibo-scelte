Sito pubblico del progetto editoriale **Animali, cibo e scelte — Capire per scegliere**.

- landing page responsive: pronta
- scelta lingua: pronta
- italiano: attivo come lingua principale
- altre lingue: predisposte e indicate come in arrivo
- PDF italiano: in preparazione
- bibliografia: in preparazione
- immagini hero: predisposti 3 slot (`assets/hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg`) con dissolvenza automatica

## Pubblicazione

Il sito è progettato per GitHub Pages dalla root del branch `main`.

## Sicurezza del progetto

Questo repository è dedicato esclusivamente al sito pubblico e ai materiali destinati alla pubblicazione. Non contiene file personali né dipende dagli altri repository dell'account.

## Struttura

- `index.html` — pagina pubblica
- `styles.css` — layout responsive per telefono, tablet e desktop
- `script.js` — scelta lingua, messaggi e dissolvenza immagini
- `assets/` — immagini e PDF pubblici quando saranno pronti

## Aggiornamenti futuri

Quando il PDF italiano sarà definitivo, il pulsante di download verrà collegato al file pubblico senza cambiare l'indirizzo principale del sito. Le traduzioni verranno aggiunte progressivamente mantenendo la stessa struttura.
